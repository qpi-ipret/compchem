Troubleshooting

Troubleshooting

오류 메시지를 외우기보다 파일 문제인지, 입력 문제인지, 프로그램 환경 문제인지 순서대로 구분하는 것이 중요합니다.

수소가 예상과 다르게 붙어요

먼저 확인

  • 총전하와 protonation state를 확인했는가?
  • Adjust Hydrogens와 Add Hydrogens를 중복 사용하지 않았는가?

가능한 해결

자동 수소 추가는 구조 작성 보조 기능입니다. pH와 tautomer/protonation 상태가 중요한 계산에서는 화학적 상태를 별도로 확인하세요.

구조 최적화 후 geometry가 이상해요

먼저 확인

  • 현재 분자에 적절한 force field parameter가 있는가?
  • 금속이나 특수 결합 환경이 포함되어 있는가?

가능한 해결

다른 force field를 무작정 시도하기보다 현재 구조에 사용할 수 있는 parameter 범위를 확인하세요.

ORCA 명령을 찾지 못해요

'orca' is not recognized

먼저 확인

  • ORCA 실행 파일 위치를 알고 있는가?
  • PATH에 등록되어 있는가?

가능한 해결

PATH에 없다면 실행 파일의 전체 경로를 사용합니다. 예: C:\orca\orca.exe input.inp > output.out

외부 XYZ 파일을 읽지 못해요

CANNOT OPEN FILE

먼저 확인

  • XYZ 파일이 실제로 존재하는가?
  • 파일명과 확장자가 정확한가?
  • input과 같은 작업 폴더인가?
  • * xyzfile 문법이 맞는가?

가능한 해결

Windows에서는 input 마지막 줄의 EOF 처리 때문에 문제가 생길 수 있습니다. 파일 끝에 빈 줄을 추가한 뒤 다시 확인해 볼 수 있습니다.

Observed during testing ORCA 6.1.1 / Windows에서 같은 폴더의 XYZ 파일을 읽지 못했으나 trailing blank line 추가 후 정상 실행됨.

Optimization은 끝났는데 구조가 의심스러워요

먼저 확인

  • ORCA TERMINATED NORMALLY만 확인하지 않았는가?
  • THE OPTIMIZATION HAS CONVERGED가 있는가?
  • Frequency에서 의미 있는 imaginary mode가 있는가?

가능한 해결

프로그램 정상 종료, optimization convergence, minimum 확인을 서로 구분하세요.

Vina 명령을 찾지 못해요

'vina' is not recognized

먼저 확인

  • vina.exe 위치를 알고 있는가?
  • PATH에 등록되어 있는가?

가능한 해결

실행 파일 전체 경로로 실행할 수 있습니다.

Ligand PDBQT를 읽지 못해요

could not open "ligand.pdbqt" for reading

먼저 확인

  • 실제 .pdbqt 파일이 존재하는가?
  • 현재 작업 폴더에 있는가?
  • .pdbqt.txt가 아닌가?
  • .lnk 바로가기가 아닌가?

가능한 해결

실제 PDBQT 파일을 작업 폴더에 저장하고 config의 파일명과 정확히 일치시키세요.

Observed during testing 테스트 중 Windows Recent의 .lnk 바로가기를 실제 PDBQT로 착각한 사례가 있었음.

Receptor에서 non-integral charge가 많이 나와요

non-integral residue charges

먼저 확인

  • alternate conformer가 있는가?
  • water/ion/cofactor가 포함되어 있는가?
  • missing atom이나 non-standard residue가 있는가?

가능한 해결

Charge를 바로 강제 보정하기 전에 입력 구조를 먼저 점검하고 필요한 전처리 후 다시 preparation합니다.

Observed during testing 구조 전처리 전후로 문제 residue 수가 감소했고 최종적으로 residue charge 검증을 통과함.

Search box가 너무 크거나 이상해요

먼저 확인

  • ADT grid point 수를 Vina size로 그대로 복사하지 않았는가?
  • center가 실제 binding site를 포함하는가?

가능한 해결

Vina의 size_x/y/z는 Å 단위의 물리적 크기입니다. Search space는 목적에 필요한 범위로 설정하세요.

Vina pose가 여러 state로 보이지 않아요

count_states = 1

먼저 확인

  • 원본이 multi-model PDBQT인가?
  • PyMOL이 기대한 방식으로 model을 state로 읽었는가?

가능한 해결

vina_split으로 pose별 PDBQT를 만든 뒤 각각 별도 object로 load할 수 있습니다.

Observed during testing PyMOL 3.1.8에서 Vina multi-model PDBQT가 1 state로 읽혀 vina_split workflow로 수정함.

Selector-Error가 떠요

Selector-Error

먼저 확인

  • 오른쪽 object panel의 실제 이름과 명령의 이름이 같은가?
  • selection이 현재 존재하는가?

가능한 해결

존재하는 object/selection 이름을 정확히 사용하세요.

Graphical distance 표시가 불안정해요

먼저 확인

  • 수치 거리만 필요한가?
  • 현재 그래픽 환경에서 distance object가 안정적으로 생성되는가?

가능한 해결

숫자 확인만 필요하다면 get_distance atom1, atom2를 사용합니다.

Observed during testing 테스트 환경에서 graphical distance object는 반복 종료가 있었지만 get_distance는 정상 동작함.
