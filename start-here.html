기본 용어

Geometry Optimization

특정 계산 모델에서 에너지가 낮아지는 방향으로 구조를 변화시키는 과정.

Force Field

원자와 결합의 상호작용을 고전적 함수로 표현한 모델.

Receptor / Ligand

Docking에서 결합 대상 구조와 탐색할 작은 분자.

Pose

Docking이 제안한 ligand의 위치·방향·conformation.

Basis Set

전자 파동함수를 표현하는 기저함수의 집합.

RMSD

두 구조의 원자 위치 차이를 나타내는 지표. 어떤 두 구조를 비교했는지 반드시 확인해야 함.
