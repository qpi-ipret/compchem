About this guide

계산화학과 분자모델링 도구를 처음 사용할 때 프로그램 역할, 파일 형식, 메뉴, 명령어가 흩어져 있어 생기는 진입장벽을 줄이기 위해 만든 입문 가이드입니다.

How this guide was developed

  1. 실제 사용 과정에서 반복적으로 막히는 지점을 기록했습니다.
  2. 공식 documentation과 manual을 중심으로 기능과 용어를 확인했습니다.
  3. 각 프로그램을 직접 실행해 메뉴·명령어·결과 파일을 확인했습니다.
  4. 오류가 발생하면 원인을 분리해 재현하고 해결 과정을 기록했습니다.
  5. 고급 기능을 무작정 늘리기보다 초보자가 필요한 정보만 남기도록 범위를 반복적으로 조정했습니다.

AI assistance and verification

자료 조사, 오류 가능성 탐색, 웹 구현 과정에서 생성형 AI를 보조적으로 활용했습니다. 다만 프로그램 실행, 화면 캡처, 결과 확인과 오류 재현은 실제 테스트 환경에서 다시 확인했고, 사이트의 범위와 정보 구조는 사용자의 필요와 직접 경험을 기준으로 조정했습니다.

Limitations

이 사이트는 공식 매뉴얼 전체를 대체하지 않습니다. 고급 전자구조 이론, 대규모 virtual screening, molecular dynamics, 전문적인 PyMOL scripting 등은 범위에서 제외했습니다.
